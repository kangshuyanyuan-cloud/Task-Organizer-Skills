# 前提（自分の環境に合わせて書き換える）

`work-start` `work-end` `meeting-todo` の3つが、**このファイルを共通で読む**。
置き場所を変えるときは、このファイルだけを直せばよい（3つのスキルを直す必要はない）。

場所はすべて、**作業するフォルダから見た位置**。

| 項目 | 値 | 説明 |
|---|---|---|
| ステータスファイル | `STATUS.md` | いま進めている作業と次にやること。見本は `見本/STATUS.md` |
| 作業ログ | `作業ログ/` | `work-end` が日付ごとに書く（`YYYY-MM-DD.md`）。見本は `見本/作業ログ/YYYY-MM-DD.md` |
| やることリスト | `やることリスト/` | `work-start` と `meeting-todo` が出した表を保存する（`やることリスト_YYYY-MM-DD.md`） |
| 文字起こしの保存先 | `やることリスト/文字起こし/` | チャットに貼られた文字起こしを残す場所 |
| 新着を見るフォルダ | `inbox/` | 資料や文字起こしのファイルを置く場所（使わなければ「なし」） |
| Gitを使うか | 使う | 使わない場合は「使わない」。Gitの確認とコミットを飛ばす |
| Gitの作業ブランチ | `main` | 記録をコミットするブランチ。チームの決まりに合わせる |
| 記録をpushするか | しない | チームで記録を共有するなら「する」。しない場合はコミットまで |

見本（`見本/`）は、このファイルと同じ `shared/` フォルダの中にある。
